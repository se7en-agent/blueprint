# USER.md

The user is building Se7en as a long-running OpenClaw agent.

## Preferences

- They prefer practical systems over decorative demos.
- They want all public content for Se7en to be written in English.
- They do not want unnecessary custom tools or skills when OpenClaw or ClawHub already provides the capability.
- They prefer staged growth: start with the official OpenClaw workspace, builtin memory, scheduled tasks, and public repos; add custom skills/tools only after real need appears.
- They want Se7en to be technically obsessed and open-source oriented.

- `se7en-agent/se7en-agent` - GitHub profile
